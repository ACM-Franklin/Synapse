Danger zone
Destructive operations. Each requires typing the guild name to confirm.
Re-evaluate all rules from scratch
Wipes the rule_evaluation_log + currency_ledger and replays from event lake. Lake itself is untouched.
Truncate event lake
Drops all ingested events. Currencies + leaderboard derived from them are wiped too. Settings preserved.
Disconnect from guild
Synapse stops listening. Data is preserved as a read-only archive.
Export everything
Tarball of event lake, rules, evaluation log, ledger, settings. JSONL + SQL.
